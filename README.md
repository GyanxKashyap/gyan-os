# Gyan OS

**Gyan Kashyap’s portfolio, imagined as a desktop.**

A place for my projects, experiments, learning notes, and the tools I build.
Windows, a dock, and a personal workspace bring those pieces together.

![Gyan OS desktop with the Samurai Crimson Gaze wallpaper](docs/screenshots/desktop.png)

## Inside the portfolio

| App | What it shows |
| --- | --- |
| **Projects** | A collection of AI experiments, apps, browser games and web projects, with screenshots and source links |
| **About Me** | My background, skills, interests and journey as a student developer |
| **Aizen** | My language model built from scratch, with its benchmark results, training history and model details |
| **Lab** | Recorded experiments, training phases, loss curves and datasets |
| **Knowledge** | Notes and lessons from building these projects |
| **Timer** | A study timer with focus sessions, history and notes |
| **Settings** | Personal wallpapers, appearance and motion preferences |

![Project gallery inside Gyan OS](docs/screenshots/projects.png)

## Featured work

- **[Aizen](https://github.com/GyanxKashyap/aizen)** — a small language model built
  from scratch in PyTorch, with separate Chat and Story experiences.
- **[JARVIS & FRIDAY](https://github.com/GyanxKashyap/AI_CHATBOT)** — two 3D
  assistant companions for conversation, writing and engineering.
- **[Study Timer](https://github.com/GyanxKashyap/TIMER-APPv1.1)** — a personal
  study tool, adapted into a window inside Gyan OS.
- **[Lunar Focus](https://gyanxkashyap.github.io/Lunar_focus/)** — a space-themed
  focus workspace with a growing moon, study history and progress.

The desktop uses my selected **Samurai Crimson Gaze** live wallpaper, with a
matching still image when animations are disabled.

## Current status

The portfolio is being polished and reviewed. **Website deployment is deferred.**
Aizen’s Chat and Story remain local demonstrations while I continue working on
the model; there is no hosted model backend.
